# Arcads — התחלה מהירה

סקיל להפקת סרטוני UGC עם שחקני AI מול [Arcads](https://arcads.ai), ישירות מ-Claude Code.

## הגדרה חד-פעמית (3 דקות)

```bash
cp .env.example .env
# הדביקו את ה-Basic auth header מ- https://app.arcads.ai/settings/api
./scripts/check-arcads-env.sh     # ציפייה: GET /v1/products → HTTP 200
```

## איך משתמשים

פשוט מבקשים בשפה חופשית — הסקיל נטען לבד כשמזכירים Arcads / Seedance / Sora / Veo / Kling /
Nano Banana / UGC:

- "תייצר לי סרטון UGC של 15 שניות לקורס בקרי איכות — בחורה בת 30, סלפי, מדברת על תלוש השכר"
- "תנתח את הסרטון הזה ותבנה ממנו תבנית Seedance 2.0"
- "תשכפל את המודעה הזאת לקורס אחר"

## מה שחשוב לדעת

- **הסקיל תמיד מציג הערכת קרדיטים ומחכה לאישור** לפני הפקה. ההערכה מבוססת על
  `logs/arcads-api.jsonl` (עלויות אמיתיות מריצות קודמות) — המספרים יתחדדו אחרי כמה ריצות.
- **קונטקסט המותג** יושב ב-`MASTER_CONTEXT.md` בשורש הריפו — טון, קהל, מסגור מחירים, ברירות מחדל.
  כדאי לעדכן שם `productId` ברירת מחדל אחרי הריצה הראשונה.
- **תמונות ייחוס** (פנים, מוצר, לוחות סגנון) נכנסות ל-`references/` — התיקייה לא נכנסת ל-git.
- **עברית:** מודלי הווידאו לא תמיד מסנכרנים שפתיים בעברית. זרימה בטוחה — לייצר באנגלית ולהוסיף
  כיתוביות בעברית לפי המדריך ב-`.claude/skills/caption-video/`, או להשתמש בזרימת ה-scripts/actors של Arcads
  (`POST /v1/scripts`) שתומכת ביותר שפות.
- **פייפליינים כבדים** (pixar-style-ad, claymation-ad, caption-video) דורשים `ffmpeg`, `jq`,
  `node`, `whisper` מותקנים מקומית.

פירוט מלא של מה הותקן ומה שונה מול המקור: `.claude/skills/README.md`.
