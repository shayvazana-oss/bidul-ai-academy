## למה נדרש שרת בכלל

מפתח API של Anthropic הוא סוד. אם הוא יושב בעמוד HTML סטטי, כל מי שיפתח "הצג מקור"
יכול לקחת אותו ולחייב את הכרטיס שלכם. לכן הקריאה ל-Claude עוברת דרך
`api/lab.ts` — פונקציה קטנה שרצה בשרת, מחזיקה את המפתח אצלה, ומחזירה לדפדפן
רק את תוצאת הניתוח.

## שלב 1 — מפתח API

1. היכנסו ל-<https://console.anthropic.com> ← **API Keys** ← צרו מפתח חדש.
2. שמרו אותו במקום בטוח. הוא מוצג פעם אחת בלבד.

## שלב 2 — פריסה ב-Vercel

מהתיקייה הראשית של הפרויקט:

```bash
npm install -g vercel
vercel            # פריסת תצוגה מקדימה — עונים על השאלות עם ברירות המחדל
vercel --prod     # פריסה לייצור
```

Vercel מזהה את `api/lab.ts` אוטומטית כפונקציה, ואת קובצי ה-HTML כאתר סטטי.
`vercel.json` כבר מגדיר לפונקציה חלון של 60 שניות.

## שלב 3 — משתני סביבה

בלוח הבקרה של Vercel: **Settings ← Environment Variables**. הוסיפו:

| משתנה | חובה? | ברירת מחדל | מה זה עושה |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ חובה | — | המפתח משלב 1 |
| `ALLOWED_ORIGINS` | מומלץ | `https://shayvazana-oss.github.io` ועוד | רשימת דומיינים מורשים, מופרדים בפסיק |
| `RATE_LIMIT_PER_HOUR` | לא | `12` | מכסת ניתוחים לשעה לכל כתובת IP |
| `GLOBAL_LIMIT_PER_HOUR` | לא | `120` | תקרה לכל המופע — הבלם שאינו תלוי בכותרות |
| `REVIEW_EFFORT` | לא | `medium` | עומק החשיבה: `low` / `medium` / `high` / `xhigh` / `max` |

> **על `REVIEW_EFFORT`:** טוקני חשיבה מחויבים כטוקני פלט, כך שהעלאת הערך
> מייקרת את הניתוח ומאריכה אותו. `medium` מספיק לביקורת על פוסט קצר;
> העלו ל-`high` אם אתם רוצים ביקורת עמוקה יותר ומוכנים לשלם עליה.

אחרי שינוי משתנה יש להריץ `vercel --prod` שוב כדי שייכנס לתוקף.

> **חשוב:** אם האתר יישאר ב-GitHub Pages, ודאו ש-`ALLOWED_ORIGINS` כולל את
> `https://shayvazana-oss.github.io` — אחרת הדפדפן יחסום את הקריאה (CORS).

## שלב 4 — חיבור העמוד

בראש `linkedin-lab.html` יש שורה אחת לעריכה:

```html
<meta name="lab-api" content="">
```

הכניסו לתוכה את כתובת הפונקציה שקיבלתם מ-Vercel:

```html
<meta name="lab-api" content="https://bidul-ai-academy.vercel.app/api/lab">
```

זהו. כפתור "נתחו את הטיוטה" בתחנה 4 מתחיל לעבוד.

> אם האתר עצמו נפרס ב-Vercel (ולא ב-GitHub Pages), אפשר להזין נתיב יחסי בלבד:
> `content="/api/lab"`.

## מה הפונקציה עושה

* **מודל:** `claude-opus-5` עם חשיבה אדפטיבית (ברירת המחדל במודל הזה).
* **פלט מובנה:** הסכימה מוגדרת ב-Zod ונאכפת דרך `output_config.format`, כך
  שהתשובה תמיד חוזרת במבנה קבוע שהעמוד יודע לרנדר — בלי לנחש טקסט חופשי.
* **מה נשלח:** תלוי במצב — `review` שולח את הטיוטה; `write` שולח את תשובות
  הראיון ואת תבנית המסגרת; `ideas` שולח את רשימת המסגרות ונושא אופציונלי.
  כולם מוסיפים את חמשת שדות המיצוב מתחנה 2, אם מולאו.
* **לאן זה מגיע:** מהדפדפן לפונקציה שלכם, ומשם ל-API של Anthropic. אנחנו לא
  שומרים את הטיוטה — לא בדיסק ולא במסד נתונים, והיא גם לא נכתבת ללוגים.
  שמירת נתונים בצד Anthropic כפופה למדיניות שלהם, לא לקוד הזה.
* **מה כן נשמר:** כתובת ה-IP שלכם בזיכרון המופע לשעה, לצורך מכסת הקצב בלבד.
* **אכיפת גבולות:** `zodOutputFormat` מעביר למודל רק חלק מהסכימה — `enum`,
  `maxItems` ו-`maxLength` יורדים לתיאור כטקסט מנחה ואינם נאכפים. לכן הפונקציה
  מנרמלת בעצמה: ערכים מחוץ לרשימה מתוקנים, מערכים נחתכים, וטקסטים ארוכים מקוצצים.

### הגנות מובנות

| הגנה | פירוט |
|---|---|
| רשימת מקורות מורשים | בקשה בלי כותרת Origin או מדומיין לא מוכר מקבלת 403 |
| מכסת קצב לכל IP | 12 ניתוחים לשעה (ניתן לשינוי) |
| תקרה לכל המופע | 120 ניתוחים לשעה — הבלם שאינו תלוי באמון בכותרות |
| תקרת קלט | מינימום 40 תווים, מקסימום 3,000 (המגבלה של לינקדאין) |
| תקרת פלט | `max_tokens` חסום ב-8,000 |
| טיפול בשגיאות | כל שגיאה מתורגמת להודעה בעברית, בלי לחשוף פרטי שרת |

> **מה ההגנות האלה *לא* עושות:** רשימת המקורות היא מהמורה, לא אימות —
> `curl -H "Origin: ..."` מזייף אותה בשורה אחת. גם מכסת ה-IP נשענת על כותרת
> שהפלטפורמה קובעת. הבלם האמיתי על החשבון הוא **התקרה לכל המופע**, שאינה תלויה
> בשום כותרת. אם העמוד ייחשף לקהל גדול, השלב הבא הוא מונה משותף
> (Vercel KV / Upstash) או שער אמיתי (Turnstile / Vercel deployment protection).

## עלות

הקלט משתנה לפי המצב: `review` — כ-1,000–3,500 טוקנים; `ideas` — כ-1,500;
`write` — עד כ-10,000 בראיון מלא (התבנית + עד 14 תשובות). הפלט הנראה לעין
הוא כ-500–2,500 — **אבל טוקני החשיבה של המודל מחויבים גם הם כטוקני פלט**,
ולכן העלות בפועל תלויה בכמה המודל בחר לחשוב ובערך של `REVIEW_EFFORT`.

לפי תמחור Claude Opus 5 ($5 למיליון קלט, $25 למיליון פלט), הרצפה היא בערך
**2–3 סנט לקריאה**, והתקרה חסומה ב-`max_tokens: 8000` — כלומר עד כ-20 סנט
לביקורת ועד כ-25 סנט לכתיבה מודרכת במקרה הקיצוני.

אל תנחשו — **מדדו**: כל תשובה מהפונקציה מחזירה שדה `usage` עם
`input_tokens` ו-`output_tokens` בפועל. שתי התקרות (`RATE_LIMIT_PER_HOUR`
ו-`GLOBAL_LIMIT_PER_HOUR`) הן מה שמונע הפתעות בחשבון.
